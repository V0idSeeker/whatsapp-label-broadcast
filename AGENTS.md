# AGENTS.md

## Project

Two front ends over `@wppconnect/wa-js`:

- `extension/` — Chrome MV3 extension that injects a broadcast panel into `web.whatsapp.com`.
- `server.js` + `public/` — local Express app that drives Playwright-controlled Chrome.

## Commands

- Install: `npm install`
- Run local server: `npm start` (dev: `npm run dev`)
- Rebuild extension assets after editing `extension/panel.css`: `npm run build:extension`
- Syntax check: `node --check server.js` and `node --check extension/app.js`

There is no test runner and no lint config.

## Notes

- `extension/vendor/wppconnect-wa.js` and `extension/styles.js` are generated by `scripts/build-extension.js` and are committed so the extension works with Load unpacked.
- `data/` (session, uploads, history) is gitignored.
- Local server binds `127.0.0.1`; non-GET `/api` calls require header `X-App-Request: 1`.
- Sending is rate-limited with randomized delays and is cancellable; a dry-run mode avoids sending.
